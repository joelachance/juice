Get Started

Install the SDK, init a project, and start setting secrets. No server required for local use.

Install

npm i @juice/sdk && npx juice init

juice init adds a gitignore block for .env / .juice/ and creates an empty .env if missing.

Local quickstart

1. Set a secret

Prompts for the value and appends it to .env — the value is never echoed.

npx juice set OPENAI_API_KEY

2. Read it in your app

Same call site works locally and in production — Juice picks the source.

import { juice } from "@juice/sdk";

const apiKey = await juice.get("OPENAI_API_KEY");

3. Run with secrets injected

Launch any process with secrets in its environment — nothing printed, nothing copy/pasted.

juice run -- node app.js
juice run -- npm test

Team / remote

Sign in, then manage secrets in preview and production from the same CLI.

juice auth login
juice set OPENAI_API_KEY --remote
juice get OPENAI_API_KEY --remote
juice list --remote
juice unset OPENAI_API_KEY --remote --yes

Machine tokens for CI (scoped, revocable): 

juice token create --project my-app --env prod --read-only --ttl 90d
export JUICE_TOKEN=…
juice token revoke

Default remote API: https://api.juice.run. Override with JUICE_API_URL for self-hosting.

Commands

Command Purpose
juice auth login GitHub device-flow login
juice init Scaffold .gitignore + .env
juice set KEY Add/update a secret (local or --remote)
juice get KEY Print one value to stdout only
juice list Print sorted key names only
juice unset KEY Remove a secret
juice run -- <cmd> Exec with secrets injected
juice token create Create a scoped machine token
juice token revoke Revoke a token

Agents

Prefer juice set, juice.get(), and juice run over editing .env by hand. Never print secret values; juice list shows names only. Copy the agents snippet from docs/AGENTS.snippet.md into your project's AGENTS.md or CLAUDE.md.
