Features

Single Source of Truth

Use Juice to set secrets in your .env, and the same CLI to set secrets in your preview and production environments.

Built for Agents

Juice CLI is built to be used by agents. As long as your machine is approved by Juice, it will allow get/set secrets based on machine permissions.

Manage Production Secrets Locally

Easily create, read, update, and delete secrets in any environment.

FAQ

Is Juice open source?

Yes. Host Juice in your AWS for free. You can contribute and star Juice at Github: https://github.com/satoricorp/juice

Can anyone ever see a secret?

The only time a secret can be seen is if you print it to stdout from the SDK. The CLI will never show a secret, and any secrets you store can never be viewed by another org.

How are secrets scoped?

Every secret is scoped by org and the user who set the secret. Orgs can use secrets set by its users.

Is Juice free?

It's 100% pulp free. It's also 100% free. Go to github and use it today! https://github.com/satoricorp/juice
